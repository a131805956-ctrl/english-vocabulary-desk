# 單字 App 產品方向

目前先完成 P0 資料範圍；本文件固定後續功能的資料原則，避免做介面時又重建一次資料庫。

## 核心組合

採用「Quizlet 的低摩擦操作 + Anki/FSRS 的排程 + Memrise 的多感官練習 + LingQ 的語境閱讀」。

- 點卡翻面；左滑 `Again／不知道`，右滑 `Good／知道`。Quizlet 官方免費 Flashcards 已採左右滑知道／不知道，可作為使用習慣基準：[Quizlet Flashcards](https://quizlet.com/features/flashcards)。
- 多個分類以臨時聯集組成 session，也可存成 preset；不複製卡片。Quizlet 官方也支援合併 sets：[Combining study sets](https://help.quizlet.com/hc/en-us/articles/360029638892-Combining-study-sets/)。
- 底層用 FSRS，預設 desired retention 0.90；兩鍵 Again/Good 仍可正常排程：[Anki FSRS](https://docs.ankiweb.net/deck-options.html#fsrs)、[FSRS FAQ](https://faqs.ankiweb.net/frequently-asked-questions-about-fsrs.html)。
- 每字保留例句、詞性、解碼、同反義、TTS、拼字、聽音、cloze 與 Difficult。Memrise 官方的 word information／activities 可作多感官練習參考：[Memrise Help](https://explore.memrise.com/help)。
- AI 文章做成互動 Reader：目標字高亮，點字開卡、朗讀、讀後出 cloze／理解題；單字狀態跨文章共用。可參考 LingQ 的全域已知／學習中字彙與匯入閱讀流程：[LingQ](https://www.lingq.com/en/learn-english-online/)。

## 範圍選取

首版直接使用 `data/generated/ranges.json`：

- 全部
- 單字書／來源
- 字首、字根、字尾篇
- UNIT
- 原書分類
- 後續動態範圍：今日到期、錯題、Star、Difficult、最近新增、儲存的自訂組合

選取多個 range 時對 entry 做聯集，再依 `canonical_term` 連到同一個學習身分。不同分類若有不同詞義或例句，仍可在卡片背面切換來源。

## 記憶與統計資料

每次作答都追加一筆不可覆寫的 `review_event`：

```text
event_id, canonical_term, entry_id, reviewed_at, rating,
mode, direction, response_ms, range_id, session_id,
flipped_before_answer, was_correct
```

FSRS 狀態另存：`due, stability, difficulty, retrievability, lapses, state`。作答時間用來發現「答對但很慢」，不直接餵給 FSRS 排程。

首頁優先顯示：今日 Due、新字上限、今日忘記、7 日學習／複習／聽音／拼字／文章量、最常錯與最可能忘記。Streak 可保留，但不當主要成效指標。

## 本地 AI 文章

Provider 設定採可替換介面：

```json
{
  "provider": "ollama",
  "base_url": "http://localhost:11434",
  "model": "使用者選擇"
}
```

Ollama 提供 OpenAI 相容端點與 structured outputs：[OpenAI compatibility](https://docs.ollama.com/api/openai-compatibility)、[Structured outputs](https://docs.ollama.com/capabilities/structured-outputs)。模型需回傳固定 schema：

```text
title, level, theme, article,
targetUsages[{wordId, sentence, form}],
comprehensionQuestions, omittedWordIds
```

程式在顯示前驗證目標字 coverage。生成文章本身不增加熟練度；只有後續回想、cloze、聽寫或理解題才寫入 review event。

## 實作順序

1. P0：目前已完成的來源、分類、canonical term、範圍與品質旗標。
2. P1：範圍選擇、翻卡、Again/Good、FSRS、TTS、例句、今日頁。
3. P2：反向卡、拼字、聽音、cloze、Star/Difficult、錯題與完整統計。
4. P3：本地 AI 文章、互動 Reader、coverage 驗證與讀後練習。
