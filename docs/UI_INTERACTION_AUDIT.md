# 行動版 UI 互動稽核

本輪以挑剔使用者的視角檢查手機操作，基準視口是 Samsung A54 常用 CSS 尺寸 `412 × 915`，並以 `405 × 720` 做窄版回歸。

## 十個被修掉的摩擦點

1. 歷史文章藏在長頁面底部：閱讀索引移到文章工房最前方。
2. 歷史文章太多會把產生器推得很遠：索引清單改成固定高度、區塊內捲動。
3. 開啟文章後看不到文章內容：開啟／生成後自動捲到文章結果。
4. 看完文章要找歷史清單很慢：文章結果提供「歷史文章」一鍵返回。
5. 手機面板像浮動小窗：文章與範圍面板改為滿版 `100dvh`。
6. 範圍選完舊選項很難找：面板顯示目前選取的可移除標籤。
7. 想換一整套範圍要逐一取消：新增「清除選取」，可留空再重新勾選。
8. 文章單字勾選後找不到已選項：在清單上方顯示已選單字標籤。
9. 篩選後再次按「選取」沒有反向操作：按鈕會在「選取目前篩選／取消目前篩選」間切換。
10. 範圍樹的勾選框放在 `summary` 內造成巢狀互動：改成純展開標題＋獨立勾選列，鍵盤與輔助技術更穩定。

## 十個完成的互動改善

1. 範圍搜尋可一鍵清除，搜尋結果會自動展開對應 LEVEL。
2. 範圍標籤可單獨移除；只剩最後一個時會清成空白待選狀態。
3. 清空範圍後「開始」會明確停用，避免誤建空 session。
4. 文章單字標籤可單獨移除，不必回到長清單尋找。
5. 文章候選單字保留最多 12 個，超過上限仍會用即時提示說明原因。
6. 篩選單字後可批次選取或批次取消，且保留原本選取順序。
7. 文章歷史清單可直接開啟，並保留主題與使用單字。
8. 刪除文章仍採二次確認，且刪除中的其他操作會鎖定。
9. 手機生成按鈕固定在面板底部可觸及區域，長文章也不用回頭找按鈕。
10. 行動面板處理安全區、滿版高度與內部捲動，A54／窄版都不產生水平溢位。

## 驗證方式

- `npm run check`
- `npm run android:build`
- Chrome mobile interaction pass at `412 × 915` and `405 × 720`
- Lighthouse mobile audit on the local build
